# 🧪 Interactive Periodic Table of Elements

A clean, semantic, and structured **Periodic Table of Elements** built using pure **HTML5** and **CSS3**. This project demonstrates practical implementation of CSS Grid, Flexbox, and semantic HTML architecture.

---

## 🌟 Key Features

* **Semantic HTML5:** Built using proper tags, attributes, and accessible structure.
* **Modern CSS Styling:** Color-coded element categories, custom borders, and smooth visual styling.
* **Grid Layout:** Accurately mimics the authentic layout of the standard periodic table using CSS Grid.
* **Interactive Design:** Clean visual hierarchy with hover features for enhanced readability.

---

## 🛠️ Built With

* **HTML5:** Page structure, element details, and content organization.
* **CSS3:** Custom layouts, color variables, grid architecture, and styling.
